# Hasid - Small Investor Platform 

A smart web platform that helps beginner investors manage their finances and make informed investment decisions using Artificial Intelligence.

> Graduation Project - UQU — 2026

---

##  Features

- **Smart Dashboard** — Comprehensive view of financial status, expenses, and income
- **AI Stock Predictions** — Analysis and prediction of Saudi stock prices
- **Portfolio Management** — Track investments, profits, and losses
- **Community & Challenges** — Interact with other investors and join financial challenges
- **Points & Levels System** — Incentives to encourage financial commitment
- **Bilingual Support** — Arabic and English
- **Dark Mode** — Eye-friendly interface

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Python (v3.10+)

### Installation

**1. Clone the repository:**
```bash
git clone https://github.com/rayanaSamer/small-investor-platform.git
cd small-investor-platform
```

**2. Install frontend dependencies:**
```bash
npm install
```

**3. Install Python dependencies:**
```bash
pip install -r requirements.txt
```

**4. Run the frontend:**
```bash
npm run dev
```

**5. Run the Flask server:**
```bash
python predict_api.py
```

**6. Open in browser:**
```
http://localhost:5173
```
